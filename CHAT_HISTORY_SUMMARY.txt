REGISTRO #001 - Correção Crítica: Autenticação Quebrada + Setup MCP Playwright
================================================================================

📅 DATA: 2025-10-17
👤 DESENVOLVEDOR: Bruno
🤖 ASSISTENTE: Claude Code (Sonnet 4.5)

---

🎯 PROBLEMA IDENTIFICADO:
- Login/registro com Auth0 (Google, email) falhava 100% das vezes
- Usuários eram redirecionados para homepage ao invés do dashboard após autenticar
- Tokens do Auth0 eram perdidos no processo

---

🔍 DIAGNÓSTICO (ROOT CAUSE):
A rota `/auth/callback` estava completamente AUSENTE do sistema de roteamento React.

EVIDÊNCIAS:
✅ AuthCallback.tsx existia (4.6KB, criado em Oct 16)
✅ Login.tsx redirecionava para /auth/callback
✅ Register.tsx redirecionava para /auth/callback
✅ auth0.ts configurado com redirect_uri = /auth/callback
❌ AppRoutes.tsx NÃO importava AuthCallback
❌ AppRoutes.tsx NÃO registrava a rota /auth/callback
❌ Catch-all route (path="*") capturava /auth/callback e redirecionava para /

FLUXO QUEBRADO:
Google → Auth0 → /auth/callback → [Rota não existe] → Catch-all → / (homepage) ❌

---

✅ CORREÇÃO APLICADA:

ARQUIVO: src/routes/AppRoutes.tsx

MUDANÇA 1 (linha 39):
+ import AuthCallback from '../pages/AuthCallback';

MUDANÇA 2 (linha 82):
+ {/* Auth0 callback - CRITICAL: Must come before catch-all route */}
+ <Route path="/auth/callback" element={<AuthCallback />} />

RESULTADO:
Google → Auth0 → /auth/callback → AuthCallback processa → /dashboard ✅

STATUS: ✅ CORRIGIDO (aguardando teste em produção)

---

Instalar e configurar Playwright MCP Server para automação de testes browser.
